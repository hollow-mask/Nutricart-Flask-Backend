# Nutricart-Flask-Backend
# React + Vite

# 🍎 NutriCart

NutriCart helps users make cost- and calorie-smart grocery choices by analyzing nutritional value per dollar and suggesting affordable, balanced recipes.

## Tech Stack
- Frontend: React (Vite)
- Backend: Flask
- Libraries: Flask-CORS, requests

## Run Locally

### Backend
```bash
cd server
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
